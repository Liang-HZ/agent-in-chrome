扩展装好了，还差本机那一半

Agent in Chrome 分两半：这个扩展（浏览器那一半）+ 本机组件（把你的 AI agent 和浏览器接起来的那一半）。浏览器扩展没有文件系统，装不了本机组件——这一行命令是唯一省不掉的一步。

在终端里跑这一行（需要 Node.js）

npx @liang-hz/agent-in-chrome@latest install

它会写各浏览器的 native host 清单、把 MCP server 注册到本机检测到的 agent （Claude Code、Claude Desktop、Codex、Trae……），改动逐项打印、全部可逆。不用重启 Chrome—— 装完扩展 30 秒内自动连上，等不及就点扩展图标里的「重连」。

不想开终端？把这句话交给你的 AI agent

帮我跑一下 npx @liang-hz/agent-in-chrome@latest install，装 Agent in Chrome 的本机组件

验证：在 agent 里说「列一下我打开的标签页」，能列出来就说明整条链路通了。 详细文档见 agent-in-chrome.liangai.org。
